# Data placement

**Each piece of data lives next to its main reader.**

| Store | Contents | Main reader | Credentials |
|---|---|---|---|
| DO SQLite | Heads, epochs, agent epochs, leases and placement claims, segment and generation indexes (with pins and loss records), the base-generation index, current state, grants, channel messages (up to about 32 KB) and cursors, tunnel ids per sandbox host and the three desired versions per cell (FleetDO) | Control plane | — |
| R2 | Session segments (native Claude Code session files), large and older (7+ days) channel message bodies (`channels/<channel>/b/<id>`), audit logs (egress, credential issuance), UI artifacts (diffs, screenshots), exported journals | DOs, UI, agents, me | DO bindings only |
| S3, per cell (Express One Zone for hot data) | Disk chunks, memory pages, generation manifests, including base generations | Hosts | Instance role |

- **Cross-cloud traffic is small text:** transcripts from brain hosts to Cloudflare, session files back from R2 when a brain starts on a new host, and hands frames between a brain and its sandbox's gateway over the tunnel. No bulk data crosses.
- **Bindings are verified, not stored.** SandboxDO signs them with the cell's binding key, which FleetDO holds and pushes to each sandbox host's gateway; nothing records an issued binding. See [../sandbox/gateway/](../sandbox/gateway/).
- **R2 is the one global store for the control plane.** Each cell has its own S3-compatible store. See [../sandbox/state/object-store/](../sandbox/state/object-store/).

## Retention

Every DO table that would otherwise only grow has one retention rule, a named constant next to the code that applies it. A row something still depends on is never dropped.

| DO | Table | Kept | Why |
|---|---|---|---|
| FleetDO | `commands` | 24 h after its result (`COMMAND_RETENTION_MS`). A host's death answers what it never did, with an error and no failure handling; a command for a dead or unknown host is answered so at once and never queued. | Results are read back right after they arrive; a dead host never answers. |
| FleetDO | `hosts` (with its `commands`, reliable channel and `tunnels_created` rows) | 7 days after it died (`DEAD_HOST_RETENTION_MS`), and only once its death is proof (`lost`: lease expired or death confirmed), its tunnel and record are deleted (the row's ids are null), and no lease, stale incarnation, reassignment, eviction or brain-index row (`host_agents`) names it. | The tunnel sweep retries deletes from the row; AgentDO asks for a brain's host's status and kill progress until it released the brain; operators look at recent deaths. |
| FleetDO | `host_agents` (the brain index) | Never pruned: a row goes only when AgentDO took the brain's exit or its host's loss for it ([fleet](../control-plane/durable-objects/fleet/)). | The one-brain rule depends on it. |
| FleetDO | `leases`, `reassign_queue`, `evictions` | Bounded by live entities: one lease per placed sandbox, deleted on release, eviction or reassignment; queue rows deleted once SandboxDO took them (retried from the tick). | Each is work in flight. |
| FleetDO, AgentDO | `rel_out`, `rel_state` (reliable channels) | `rel_out` until acked (reset when the peer restarts or dies); `rel_state` one row per channel, dropped with a pruned host. | Resend after a reconnect. |
| Every DO | `deadlines` | One row per armed deadline, deleted when it runs. | Multiplexes the one alarm. |
| FleetDO, SandboxDO, WorkstreamDO, AgentDO | `kv` | A fixed set of keys per object (FleetDO: the zone id per zone, the cell, the mark counter, the root CA, the last prune, a GC request). | Bounded by construction. |
| CatalogDO | `capabilities`, `templates`, `kv` | Keyed by name: bounded by the entries an operator writes (`kv` holds only the seeded flag and the seed version). | They are the catalog. |
| ChannelDO | `messages` | Per channel, `retention_days` (default 30, `DEFAULT_RETENTION_DAYS`), from the daily `maintenance` deadline; the newest message per key is kept while it is the newest (its row is what the keyed view points at). Bodies older than 7 days (`TIER_AFTER_MS`) and over 32 KiB live in R2 (`channels/<channel>/b/<id>`), deleted after their row. Built-in channels (`<agt>/inbox`, `<agt>/events`, `<sbx>/events`, `user`) use the default. | Readers page with `since`; the keyed view is shared state. |
| ChannelDO | `keys` | One row per live key; a keyed post with no text removes it. | It is the keyed view. |
| ChannelDO | `idem`, `rate` | Idempotency keys 7 days (`IDEM_RETENTION_MS`); a rate window once it ended. | A retried post lands once within a call's outcome lifetime. |
| ChannelDO | `subs`, `acl`, `kv`, `directory` | Bounded by live subscriptions (removed by `unsubscribe`, a `once` delivery, or a subscriber that isn't an agent), the grant list the operator sets, a fixed set of keys (`meta`, `head`), and (`~directory` only) one row per channel. | They are the channel's state. |
| AgentDO | `channel_subs` | One row per subscription it has; an ended (`once`) one 7 days. | The high-water `seq` deduplicates deliveries. |
| AgentDO, SandboxDO | `chan_out` | Until ChannelDO acknowledged the post. | Its `<agt>/events` or `<sbx>/events` post is owed. |
| BrokerDO | `secrets` | Keyed by name: bounded by the names an operator writes; an expired value stays (refused when resolved) until overwritten or deleted. | An operator sees what to renew. |
| FleetDO | `tunnels_created` | With its host's row; without one, until a sweep whose two listings both succeeded and were complete shows neither the tunnel nor the record, past the hour's grace. A listing stops at 10 pages of 100 (`lib/cloudflare.ts`) and then says it is incomplete, so a large account only delays forgetting. | It is what the sweep may delete: forgotten only once nothing is left to delete. |
| FleetDO | `launched` | 7 days after EC2 confirmed it gone (`LAUNCH_RETENTION_MS`); never before. Confirming a host dead marks its instance to terminate, so every launched instance ends. | The record is what terminates the instance and confirms it gone. |
| FleetDO | `stale_incarnations` | 24 h after its `sandbox_destroy` was issued (`STALE_INCARNATION_RETENTION_MS`). | The destroy is sent once. |
| FleetDO | `enroll_tokens` | 7 days after use (`ENROLL_TOKEN_RETENTION_MS`). An unused token stays until used. | A used token can't be used again. |
| FleetDO | `gc_runs` | 30 days after it finished (`GC_RUN_RETENTION_MS`); the latest run, the latest proven run (so the next run isn't dry again) and an unfinished run always. | GC history for the operator. |
| FleetDO | `sandboxes` | Live rows always; a destroyed one 30 days (`DESTROYED_SANDBOX_RETENTION_MS`). | Its generations stopped being GC roots when it was destroyed. |
| SandboxDO | `commits` (idempotency records) | A rejected request's record 7 days (`COMMIT_RECORD_RETENTION_MS`); a committed one while its generation is in the chain (all of them, today). Pruned from an hourly deadline, never on the commit path, through the indexed `generation_id`. | nestd asks again with an unanswered request's id before its next commit, possibly days later: a committed request finds its record while its generation is kept; any other meets the compare-and-set again, as a new request would. |
| SandboxDO | `epochs` (which host held which epoch) | The sandbox's life. The blob's capped `history` is merged in on every start and, for one release, still written (from the table), so a rollback keeps authorizing recent salvage and a re-upgrade loses nothing. | Salvage from any older epoch is authorized against it; one small row per placement. |
| WorkstreamDO | `events`, `user_notifications`, `applied` | The latest 5,000 and 1,000 rows; idempotency keys 7 days. | Bounded history. |
| AgentDO | `tool_calls`, `asks`, `turns`, `inbox` | Finished rows 7 days; `events` the latest 500; `seg_buffer` until its bytes are acked. | Bounded history. |
| AgentDO | `segments` (the transcript's R2 segment index) | The agent's life; rows of a superseded base aren't dropped yet (a gap). | The transcript is rebuilt from them. |
| SandboxDO | `grants` | Until each expires (the `grants` deadline deletes it). | Bounded by live grants. |
| SandboxDO | `generations` | All of them: generation retention isn't built. | Every generation is a GC root. |

FleetDO prunes at most once an hour, from any alarm: the tick while a host is live, the daily tunnel sweep, and its own daily `prune` deadline (armed on every start, so a quiet cell without tunnels still prunes). A dead host left at `lost` = 0 (an idle or drained retirement whose termination EC2 never confirmed, e.g. a cell without EC2 access) is never pruned, nor are the kill commands FleetDO answered for a host at `lost` = 0 (dead or alive): its death isn't proof (A6), and AgentDO reads a missing kill command as processed. FleetDO's other answers go after their retention. Generations themselves (and so GC roots) aren't thinned yet: generation retention isn't built ([state](../sandbox/state/#retention)).

## Enums

The rule covers columns; closed sets inside a stored JSON body are parsed with their zod schema on read instead (CatalogDO skips and logs a row that fails; AgentDO reads its spec's `escalate_to` through `storedEnum`). Every status, state, kind and type column (FleetDO's `hosts.status`, `role` and `tunnel_state`, `leases.state`, `commands.type` and `purpose`, `launched.role` and `reason`, `enroll_tokens.role`; SandboxDO's `state`; WorkstreamDO's `events.type` and `user_notifications.urgency`; AgentDO's `turns`, `inbox`, `tool_calls` and `asks` status; ChannelDO's `acl.action` and `directory.kind`, and a subscription's `delivery` inside its JSON body) has a closed TypeScript union, shared with the wire types where one exists (`SandboxState`, `TunnelState`, `HostRole`, `CommandBody["type"]`, `WorkstreamEvent["type"]`); writes go through it, and every read is checked (`control-plane/src/lib/stored.ts`): a value outside the union is logged as an error and returned as read, so one bad row cannot stop a DO. There are no SQLite `CHECK` constraints: SQLite can add one only by rebuilding the table, which on live DO data is a risky migration for a guard the types already give. A column whose null used to mean a value (`hosts.tunnel_state`, null for `none`) is written explicitly and migrated once, and so is a renamed member (`burst` and `controller` in the three `role` columns became `sandbox` and `brain`). The admin views (`GET /v1/admin/fleet`, `/v1/admin/images`) are typed by the contract `protocol/admin/view.ts`, which imports nothing, so the dashboard checks its client against it with type-only imports and never imports the control plane; the control plane asserts at compile time that its enums equal the protocol's. Flags (`hosts.lost`, `brain_epochs`, `host_agents.gone`, `drain_told`) are 0/1 integers; AgentDO's brain record phases live in its JSON state, not in columns.

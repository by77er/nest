# Gateway

**The only network door into a sandbox.** One unprivileged process per sandbox host. Previews, terminals and hands are three routes behind the host's one tunnel hostname, so a brain, a person's terminal and a browser all enter the same way, from wherever they run. Wire contract: [../../interfaces/gateway/](../../interfaces/gateway/).

```
brain host · laptop · AgentDO ─► Cloudflare Access (service token) ─► Tunnel ─► cloudflared on the sandbox host
   ─► gateway: verify the binding, pin (sandbox, epoch) on every frame
   ─► Firecracker vsock unix socket: "CONNECT 1025" (hands, call_status) · "CONNECT 10000" (PTY, ingress) ─► guest agent
```

- **Routes:** `/hands` (one WebSocket per hands call, and `call_status`), `/pty` (terminal attach and reattach), `/ingress/<port>` (previews, `nest port-forward`). Each is one connection per call or stream, forwarded to the guest's vsock port; the [host-guest](../../interfaces/host-guest/) frames pass through verbatim.
- **What it checks.** Cloudflare Access admits only holders of the service token at the edge. The gateway verifies the binding (signature, expiry, scope, client) and that its epoch is the VM's current epoch, then pins `(sandbox, epoch)` on every frame; the guest checks the epoch again. Two checks, one rule. A binding for another epoch gets `stale_epoch`; a sandbox that isn't on this host gets `moved`.
- **Cancel is a close.** A dropped WebSocket closes the vsock side, and the guest kills the call's cgroup: a hangup is a cancel, whoever hung up (the brain, a network partition, a gateway restart). Terminals keep the 60 s detach grace the [guest agent](../guest-agent/#terminals) gives them.
- **No state, one secret.** The gateway stores nothing. It holds the cell's binding verification key and the current revocation set, pushed by nestd over `/run/nest/gateway.sock`; nestd receives them from FleetDO over the fleet channel, as it receives policy secrets. nestd launches the gateway with file permission on the VMs' vsock sockets (no privileges, no `setns`) and restarts it if it dies. A restart cancels open calls through the hangup; bindings are unaffected, since they're verified, not stored.
- **Addressing.** cloudflared on the host dials Cloudflare outbound on port 7844 (QUIC, falling back to HTTP/2) and keeps the connection open; the host accepts no inbound connection. The Worker creates one tunnel and one proxied CNAME per sandbox host at enrollment (`<host>-gw-nest.<zone>`, a proxied CNAME to `<tunnel-id>.cfargotunnel.com`: a first-level label of the zone, so Universal SSL covers it, and on no Worker route; see [setup](../../setup/#hostnames)) and returns the tunnel token in the enrollment response; FleetDO deletes both when it terminates the host, and a daily sweep removes leaks ([remote tunnel API](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/get-started/create-remote-tunnel-api/)). Clients learn the hostname from SandboxDO's `resolve`. **Tunnel-only to start:** a VPC endpoint for same-cell brain hosts is a latency shortcut, added only if a measurement asks for one. A client needs only outbound HTTPS, so a brain host in any VPC, a laptop and a Durable Object reach a sandbox the same way.
- **Auth layers:** the Access service token at the edge (the Worker, AgentDO and brain hosts hold it from BrokerDO; a laptop gets it through a `nest` login; a sandbox never holds it), the binding at the gateway, the epoch in the guest.
- **Versions.** The gateway serves guest protocol versions in `[min_supported, current]` and speaks each guest's version; `resolve` reports the guest's `protocol_version` and `capabilities`, so a client sends only what the guest advertised ([host-guest versions](../../interfaces/host-guest/#versions-v2)). The gateway's own protocol has the same range, so a brain host and a sandbox host can be one release apart in either direction. Frames stay within the host-guest 16 MiB limit; nothing is chunked.
- **What it must not know:** which backend drives a client, its model or prompt, whether the client is an agent or a person, where the client runs or which path it took, and which grants led to the binding. It knows a client id, an epoch and a scope.
- **Failure.** A Cloudflare edge or tunnel outage takes every route down; sandboxes keep running and clients wait. An unreachable control plane changes nothing for open bindings until they expire (about an hour).

**Not built:** the gateway, bindings, tunnels and the Access token. Today the runner connects to the guest's vsock socket directly on the sandbox's host, and previews, terminals and port-forwards have no router; `control-plane/README.md` and `crates/nestd/README.md` list the gaps.
